# ADR-0013: dotenv 주입과 CI 생성 설정 준비

- 상태: 채택. 환경 파일 경로는 [ADR-0018](0018-environment-directories.md)로 변경한다.
- 대체: ADR-0012의 로컬 암호화·키체인 방식

## Problem 1-Pager

- 배경: 기본 개발은 더미 설정, 실제 연동은 dotenvx와 키체인을 사용했다. CI는 `pnpm verify`로 타입 기반 린트를 먼저 실행한다.
- 문제: 로컬 암호화·복호화 키 관리가 현재 개발 규모에 비해 복잡하다. 새 CI 환경에는 앱 tsconfig가 상속하는 `.void/tsconfig.json`이 없어 린트가 실패한다.
- 목표: 로컬 주입은 일반 dotenv 명령으로 단순화하고 CI의 생성 파일 의존성을 명시한다.
- 비목표: 운영 Worker Secrets 교체, 운영 배포, 기존 암호화 보관본 삭제, AI 격리 환경 구현.
- 제약: 명령 이름 `dev` 유지, 실제 비밀값 커밋·로그 출력 금지, 기본 개발·테스트의 실제 외부 호출 방지.

## 대안

| 대안                                        | 장점                                    | 단점·위험                                                       | 결정   |
| ------------------------------------------- | --------------------------------------- | --------------------------------------------------------------- | ------ |
| 모든 로컬 명령이 루트 `.env` 사용           | 파일과 명령이 가장 적음                 | 일반 개발·E2E에 실제 외부 서비스 설정이 전달될 수 있음          | 미채택 |
| 더미 설정과 실제 `.env`를 dotenv-cli로 구분 | 키 관리 없이 기존 개발·테스트 분리 유지 | 주입 스크립트 두 개 유지                                        | 채택   |
| dotenvx·키체인 유지                         | 저장된 파일 암호화                      | 현재 요구보다 복잡하며 같은 OS 사용자의 AI 접근은 차단하지 못함 | 대체   |

CI는 명시적 codegen 단계와 모든 검사 명령에 codegen을 결합하는 대안을 비교했다. 앱의 `codegen`을 CI의 검증 직전에 실행한다. 독립적인 검사 명령에 숨은 준비 작업을 추가하지 않는다.

## 결정과 영향

- `with-env`는 공개 더미 파일을, `with-env:real`은 Git에서 제외한 루트 `.env`를 읽는다. `dotenv --no-expand -o -e <파일> --`로 주입한다.
- dotenvx 직접 의존성과 `env:encrypt`·`env:keychain`을 제거한다. 이전 로컬 실제 설정은 값 출력 없이 `.env`로 이전한다. `config/env/archive/`의 세 파일도 원래 경로에 평문으로 복구하고, 암호화 원본은 Git에서 제외한 `config/env/.env.encrypted-backup/`에 보관한다.
- 기본 개발·테스트는 메모리 응답과 SMS 로그 모드를 유지한다. 가정은 ADR-0012와 같다.
- `.env`는 평문이다. AI의 파일 접근 차단은 저장소 설정만으로 보장하지 않는다.
- 운영은 Cloudflare Worker Secrets를 계속 사용한다. dotenv를 Worker 런타임에 추가하지 않는다.
- 앱의 `codegen`은 `void prepare`다. CI는 `pnpm --filter web run codegen` 후 `pnpm verify`를 실행한다.
- 새 clone에서 검증만 실행할 때도 `pnpm -C apps/web codegen`을 먼저 실행한다.

## 검증

- 생성된 tsconfig가 없는 상태에서 기존 오류를 재현했고, CI의 codegen 명령 후 `pnpm verify`가 통과했다.
- 실제 CLI 테스트에서 더미 설정 덮어쓰기, 평문 주입, `$`와 여러 줄 값 처리 및 값 미출력을 확인했다.
- `pnpm verify`: 테스트 299개 포함 통과. 웹 빌드와 공개 신청·관리자 인증 E2E 4개도 통과했다.
- 이전된 실제 `.env`는 값을 출력하지 않은 스키마 검사와 Git 제외 확인을 통과했다. 보관본 세 파일은 복호화 전후의 값 일치, dotenv 파싱, 권한 `600`, Git 제외를 확인했다.
- 기존 Turbo 타입 검사 캐시 output 경고와 CSS sourcemap 경고는 남아 있다. 운영 배포는 수행하지 않았다.
