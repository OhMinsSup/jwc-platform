# ADR-0008: typie 기준 디자인 언어 (토큰, 글꼴, 앱 셸, 안내 상자)

- 상태: 채택 (Accepted)
- 작성일: 2026-11-04

## Problem 1-Pager

- **배경**: 공개 신청 화면과 관리자 콘솔이 shadcn 기본 토큰 + 앱별 강조색(라즈베리)으로 그려져 있었다. 같은 의미(선택, 안내, 오류)가 화면마다 다른 모양이었다.
- **문제**: 색이 의미 없이 쓰이고(선택/탐색에도 강조색), 다크 모드가 클래스 토글이라 실제로 켜지지 않았다. 안내/오류 상자가 파일마다 손으로 만든 클래스였다.
- **목표**: typie.co(마케팅 페이지, 로그인, 앱 편집기 화면)에서 측정한 값으로 토큰·글꼴·반경·셸·안내 상자를 한 벌로 맞춘다. 시스템 설정을 따르는 라이트/다크.
- **비목표**: typie 제품 화면 복제, 로고/일러스트/문구 차용. 편집기 기능.
- **제약**: `@jwc/ui`(shadcn 생성물)는 최소로만 고친다. 앱 토큰은 `apps/web/src/styles.css`, 패턴 기본값은 `@jwc/ui-patterns/styles.css`.

## 결정

| 항목      | 값                                                                                                                                                       |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 색        | 무채색 기본. 주 버튼은 잉크 반전(#17181c / 다크 #f1f1f7). 색은 상태·데이터에만: 성공/납입 초록, 주의 주황, 위험 빨강, 정보 파랑                          |
| 면        | 바탕 #f9fafd / 카드 #fff / 옅은 면 #f3f4f7 / 한 단계 #eff0f3 / 눌림 #e6e7ea. 다크: #0a0b0e / #131317 / #1d1d21 / #222226 / #28282c                       |
| 선        | 옅은 선(rule) #eeeff2, 기본 선(border, 입력 테두리) #dfe0e3, 진한 선(border-strong, 입력 hover) #d0d1d4. 다크: #2c2c31 / #444449 / #606065               |
| 글꼴      | UI는 SUIT Variable, 큰 제목은 Wanted Sans Variable (둘 다 OFL, jsDelivr). 자간 -0.015em, 한글은 어절 단위 줄바꿈                                         |
| 반경      | 작은 컨트롤 8px, 카드 12px, 공개 화면 주 버튼은 알약형                                                                                                   |
| 그림자    | 쉬는 상태 그림자 없음. 예외: 인증 카드와 그 주 버튼의 아주 옅은 그림자(`shadow-soft`, `shadow-soft-sm`)                                                  |
| 다크      | `prefers-color-scheme`를 따른다. `@jwc/ui`의 `dark:` 변형도 같은 미디어 쿼리로 바꿨다 (클래스 토글 스크립트 없음, CSP 친화)                              |
| 관리자 셸 | 사이드바 240px, 바탕과 같은 면 + 1px 선. 메뉴 행 32px, 선택 행은 눌림 면(#e6e7ea / #28282c)                                                              |
| 인증 화면 | 30px 모눈 바탕 가운데 400px 카드, 라벨 13px, 입력·버튼 38px                                                                                              |
| 안내 상자 | `@jwc/ui-patterns/components/callout`: 1px 어조색 테두리 + 5% 같은 색 면 + 16px 아이콘, 글자는 본문색. 손으로 만든 안내/오류 상자는 모두 이것으로 바꿨다 |
| 좁은 화면 | 응답 표는 md 미만에서 응답 카드 목록, 질문 카드의 버튼 묶음은 제목 아래 줄, 개수 거르개는 2~3열 격자 (가로 스크롤 없음)                                  |

대안 비교:

- **A) shadcn 기본 + 강조색 하나(이전)**: 변경이 적지만 색이 탐색/선택에도 퍼지고 다크 모드가 실제로 동작하지 않는다.
- **B) typie 측정값 기반 무채색 + 상태색 (채택)**: 의미별로 색이 한 번씩만 쓰인다. 토큰 수는 늘지만 모두 표 한 곳(styles.css)에 있다.
- **C) 디자인 시스템 패키지를 새로 분리**: 앱이 하나뿐이라 이르다. 토큰은 앱, 패턴은 ui-patterns로 충분하다.

## 가정 (확인 필요)

- 라이트 모드의 정보 파랑(#2f6ae0)은 측정하지 못해(사용자 브라우저가 다크) 다크 값 #4d7eec에서 명도를 낮춰 정했다.
- typie 앱 화면 측정은 스크린샷 픽셀 표본으로 했다 (브라우저의 AppleScript 자바스크립트 실행이 꺼져 있어 계산된 스타일은 읽지 않았다). 크기는 ±1px 오차가 있을 수 있다.
- `@jwc/ui` 손수정: `button.tsx`(배경 clip 제거 — 투명 테두리 때문에 주 버튼이 2px 작아 보이던 문제), `sheet.tsx`/`dialog.tsx`(닫기 버튼 화면 낭독 문구 한국어), `globals.css`(dark 변형을 미디어 쿼리로).
